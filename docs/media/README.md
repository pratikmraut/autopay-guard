# AutoPay Guard video walkthrough

[Watch or download the AI-narrated MP4](autopay-guard-ai-narrated-walkthrough.mp4).

## Contents and scope

This five-minute interview rehearsal explains the personal project's problem,
architecture, transactional notification outbox, worker leases, retry policy,
delivery limitations, concurrency controls and selected automated-test source.
The visuals are rendered diagrams and actual code excerpts, not a live browser
or screen recording. The narration retains the original Akanksha introduction
and Better interview closing.

The audio is generic synthetic speech generated with Microsoft David Desktop.
It is not Pratik Raut's recorded voice or a clone of his voice. No personal
voice recordings are included in this directory.

The application tracks fictional recurring commitments; it does not execute
payments. The video does not demonstrate a healthcare integration, production
deployment, current CI success or a fresh application test run.
